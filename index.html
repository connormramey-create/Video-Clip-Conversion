    1. Open your repo's public/videos upload page (or go to the folder on GitHub → Add file → Upload files).
    2. Drag in the file and press Commit changes. Use Upload files, not "Create new file", which would make an empty file.

    Tips and troubleshooting
    • Aim for 3–10 seconds: one or two clean reps. The app loops the clip.
    • Film with the phone held still, and keep the whole movement inside the square.
    • Works best in Safari (iPhone/Mac) or a recent Chrome / Edge. Firefox usually can't read iPhone (HEVC) videos.
    • If a browser can't read your video, set iPhone Settings → Camera → Formats → Most Compatible and film again.
    • If colors look washed out, the video was filmed in HDR. Turn off Settings → Camera → Record Video → HDR Video for demo clips.
    • Upload the .mp4 this page makes, not the original .mov. The app only picks up .mp4 and .webm files.
